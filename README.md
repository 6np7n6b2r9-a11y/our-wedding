# Our Wedding

Персональный свадебный сайт.

Сейчас в репозитории находится первая рабочая версия сайта в `index.html`.

## Следующие шаги
1. Переключить репозиторий в Public.
2. Включить GitHub Pages: Settings → Pages → Deploy from a branch → main → /root.
3. Добавить имена, дату, адрес площадки и фотографии.
4. Подключить сохранение RSVP гостей.
